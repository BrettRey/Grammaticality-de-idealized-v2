# Terminological-hygiene pass

Manuscript: `operator-stratum.tex`
Date: 2026-08-25

## Result

The paper now keeps its principal terms and local contrasts stable. The mechanical
terminology gate reports zero unglossed watchlist terms in the front matter.

## Local contrasts traced

| Contrast | Use retained |
| --- | --- |
| norm constitution / token application | what makes a relation grammatical / whether a performance conforms to it |
| target attribution / response causation | what a response identifies / why the response occurred |
| norm / assembly profile | the socially sustained standard / the analyst's fallible evidential estimate |
| assembly profile / discourse-consequence profile | evidence about norm organization / evidence about effects on discourse organization |
| repertoire / scope | conventional resources / the community, activity, medium, and period over which the claim is made |
| value / exponent | a conventional alternative selected or realized in a constructional domain / its formal realization |
| fault / response | a performance's nonconformity relative to a norm / a judgment, correction, repair, accommodation, or sanction |

## Drift repaired

- Replaced **assembly-role profile** with **assembly profile**. *Role* had begun to
  alternate between the relation's constitutive contribution and the analyst's
  representation of it. *Assembly profile* is now reserved for the latter.
- Reserved **role** for established relational uses: argument role, participant
  role, and Heltoft's illocutionary/interlocutionary roles.
- Standardized the repair contrast as **discourse-directed** versus
  **form-directed** repair. Removed competing *meaning-directed* and
  *update-directed* labels.
- Replaced front-matter **fault attribution** with **target attribution** to match
  the six-question framework.
- Reserved **scope** for repertoire scope and replaced a semantic use with
  **explanatory domain**.
- Replaced Amele table label **licensed target** with **attested conforming form**.
- Replaced **ontological/predictive defeater** in the French reconstruction with
  **evidence against the grammatical analysis/prediction**, keeping ontology,
  evidence, and outcome separate.
- Defined **value** at first substantive use as a conventional semantic,
  structural, relational, or discourse-organizing alternative selected or
  realized within a constructional domain.

## Imported and canon terms

- Boye and Harder's *discursively secondary*, Heltoft's discourse-role terms, and
  Abrusán's repairability vocabulary remain attributed and locally delimited.
- **Determinative** names the English lexical category and **determiner** the
  nominal function in the new demonstrative example.
- No category/class, determiner/determinative, non-count/mass, predicate/predicator,
  or stabilizer/controller drift was found.

No unaccepted terminology drift remains.
