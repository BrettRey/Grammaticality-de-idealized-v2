# Corpus materials and access boundary

The included CSV files record the registered agreement query plan, exact query
strings, row-coding categories, aggregate filtered counts, uncertainty
intervals, and baseline checks used for the production-choice illustration in
Supplementary File 1.

Raw COCA results and coded concordance rows are excluded. They contain corpus
text and remain subject to the English-Corpora access terms. A researcher with
COCA access can rerun the included query strings and apply
`kwic-coding-schema.csv` to independently retrieved results.

The independent-relative _whose_ sentence in the main paper has a different
status. An exploratory historical COCA search returned zero, but its exact
interface query was not preserved. The paper therefore treats it only as an
unregistered illustration and draws no licensing estimate from it. No data file
in this archive purports to reproduce that search.
