## Code-level hazards

1. **Hand-rolled evidence-flow constants are a silent-failure trap.** While setting up my own probes I inverted the unavailable-branch probability; `Math.max(0, …)` clamped the omission contrast to zero, yielding a preemption-free model whose fold structure happened to be numerically near-identical. Any sweep script must import `expectedEvidenceFlow` rather than recompute constants, and a sanity assertion (contrast > 0 in preemptive configurations) is warranted.
2. **`betaFromMoments` clamps variance to the Bernoulli ceiling silently** (revised-engine.mjs:186). Never bound in today's scan (max ratio 0.331), but if it ever binds it distorts the state without logging. Emit a flag when active.
3. **`stationaryEvidenceAtTheta` initializes from the prior on every call** (closed-loop-sim.mjs:305). Safe today only because stationarity proved unique per θ (five initializations, four θ values, identical endpoints). Fold work should include the multi-initialization check, or a future multiplicity would be invisible to the reduced-crossing classifier.
4. **Grid resolution at folds:** `findMeanFieldFixedPoints` merges fixed points closer than 1e-8 and samples on a unit grid; pairs born within ~1e-3 of each other can be missed at gridSize 120. Use gridSize ≥ 240 for continuation, 480 for cusp confirmation.
